# Tenfold Base8000 Descent

## Story
An analyst found a message wrapped in a strange high-symbol alphabet.
The sender layered the same encoding routine multiple times.

## Your Task
Decode the content of `challenge.txt` with the same Base8000 decoder repeatedly.
The correct plaintext appears only on the tenth decode.

## Rules
- Perform sequential decoding rounds.
- Do not stop early.
- Submit only the final decoded text.
- Final flag format is strictly: `ZeroSecure_CTF{caught_it_ten}`
- Keep exact characters and casing.
