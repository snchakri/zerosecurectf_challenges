# Wren

**Category:** Cryptography

An IoT device uses a deliberately small RSA private exponent for fast decryption; Wiener's attack recovers it from the public key -- which only earns the private operation. The activation token is then assembled by walking a server-gated RSA decryption token-chain (one CRC-authenticated fragment per stage; each decryption releases the next ciphertext).
