# Unison

**Category:** Cryptography

A firmware vendor broadcasts ONE signed activation record (identical for every device) encrypted with RSA exponent e=3 under many distinct moduli; combine three intercepted ciphertexts with the CRT and take an integer cube root to recover the common plaintext, which carries the flag (Håstad's broadcast attack).
