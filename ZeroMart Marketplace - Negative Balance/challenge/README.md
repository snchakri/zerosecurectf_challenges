# ZeroMart Marketplace - Negative Balance

Welcome to ZeroMart, where prices are outrageous, accounting is creative, and your wallet obeys questionable C arithmetic.

You start with 100 ZeroCoins.
The premium flag item costs 9,999,999 ZeroCoins.

Explore the menu, buy items, and try to unlock the flag.

## Challenge Details
- Category: PWN / Logic Flaw
- Difficulty: Beginner-Intermediate
- Estimated Time: ~20 minutes
- Flag format: `ZeroSecure_CTF{...}`

## Run
On Ubuntu/Linux:
1. `chmod +x ./zeromart`
2. `./zeromart`

Good luck, and remember: numbers in C follow rules, not intentions.
