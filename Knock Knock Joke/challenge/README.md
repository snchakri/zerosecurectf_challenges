**Category:** Network Forensics

# Knock-Knock Joke

A mysterious host on the network keeps knocking on doors and running away before anyone answers. No payloads, no obvious exfil stream, just a blizzard of noisy traffic and a weird rhythm of SYN packets to closed ports.

Your mission:
- Analyze the provided PCAP.
- Isolate the suspicious knock sequence from one source host.
- Recover the hidden flag encoded in TCP destination ports.

Flag format:

`ZeroSecure_CTF{...}`
