# ch4_ghost_in_the_machine - Build and Packaging

## Build contract

1. Compile C source to wasm + JS glue.
2. Assemble static web bundle.
3. Validate local browser execution from clean server path.

## Build outputs

- public/index.html
- public/module.wasm
- public/module.js
- private/source and build scripts

## Packaging

- ch4_ghost_in_the_machine_public_vX.zip
- ch4_ghost_in_the_machine_private_vX.zip
