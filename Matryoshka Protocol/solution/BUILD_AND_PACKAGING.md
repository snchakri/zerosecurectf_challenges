# ch2_matryoshka_protocol - Build and Packaging

## Build contract

- Build payload first.
- Run embed script to regenerate encrypted header/blob.
- Build wrapper second.

## Build outputs

- public/ch2_wrapper binary
- private/payload build artifacts
- private/embed metadata

## Packaging

- ch2_matryoshka_protocol_public_vX.zip
- ch2_matryoshka_protocol_private_vX.zip
