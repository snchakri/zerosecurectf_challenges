# The Prime Hour

**Category:** Cryptography

**Category:** crypto  |  **Flag format:** `zerosecurectf{...}`

The Concord counts in primes, and the Ferry leaves on the Prime Hour. A generator seeded at that
hour leaks only the high bits of each state. Recover the seed.
