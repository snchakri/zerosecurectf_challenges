# The Prime Hour — solution

Run from the title directory:

```bash
python -m pip install -r solution/requirements.txt
python solution/solve.py
```

1. Represent each published state as `H_i*2^low_bits+x_i`, with the unknown low part bounded by `2^low_bits`.
2. Express every low part as an affine modular function of the first. Build the lattice generated by the recurrence powers and modulus multiples.
3. Reduce the lattice and solve the closest-vector problem near the center of the allowed low-part box.
4. Invert one LCG step to recover the seed. Verify that the seed reproduces **all twelve** published outputs before decoding it as ASCII.

The accepted event answer is recorded in `accepted_flags.txt`. The solver derives its result from the challenge data.
