# Staged Hint Ladder: The Accelerating Decryptor

### Hint Level 1
When the private exponent d satisfies d < (1/3) * N^(1/4), Wiener showed that e/N approximates k/d.

### Hint Level 2
Use the continued fraction expansion of e/N to generate successive convergents (k/d).

### Hint Level 3
For each convergent, test whether d yields integer roots for the quadratic polynomial x^2 - (N - phi + 1)x + N = 0.
